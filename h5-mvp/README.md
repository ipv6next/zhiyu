# 知遇 H5 MVP

产品版本 v0.2.0。根目录运行 `python premeet-backend/server.py`，浏览器访问 http://127.0.0.1:4180/ 。不要直接双击 HTML 文件。

用户流程：本地账号登录 → 资料与偏好 → 轻量分身建档 → 可选 AI 访谈 → 推荐/预会面 → 独立决定 → 本地真人接管服务状态。

会员中心、数字分身档案和轻量建档页均提供独立访谈入口。访谈支持换题、跳过、暂停恢复、来源资料修正，以及普通偏好的使用范围控制。每条新访谈回复标记实时模型生成、混合或预设来源。

原 11 题、已有档案与会后校准继续保留。注册身份一致，付费权益由现有本地后台管理。DeepSeek 密钥仅在后端配置；本地账号和上传照片不随 GitHub 版本发布。

测试方法、启动与版本变更见根目录 `README.md` / `CHANGELOG.md`。仍未接真实支付和微信能力，当前为本地 MVP。
