# 知遇 H5 MVP

本地预览：http://127.0.0.1:4180/ 。服务启动方法见 ../premeet-backend/README.md 。

当前本地体验闭环：选择测试身份 → 资料草稿 →（会员）数字分身档案 /（候选真人）会员浏览 → AI 预会面 → 回顾与独立决定 → 双方同意后的 7 天真人接管服务。

DeepSeek仅在后端配置密钥后调用；本轮已使用当前环境配置完成真实API测试。无密钥时标注规则演示。仍未接真实用户、支付、微信、身份核验、真人聊天或正式匹配数据库。

本地体验首页提供“会员”和“候选真人”两种测试身份，切换身份只用于验收双边流程。资料页数据暂存在浏览器中。4180、旧4173、直接file打开属于不同来源，原本地资料不会自动迁移。预会面通过4180服务访问，不要直接双击HTML。
