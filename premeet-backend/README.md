# 知遇本地预会面服务

当前产品版本 v0.2.0，详见根目录 `VERSION`、`README.md` 和 `CHANGELOG.md`。

在项目根目录运行 `python premeet-backend/server.py`，打开 http://127.0.0.1:4180/ 。只监听本机。

## 模型配置

将本目录 `.env.example` 复制为 `.env`，设置 `DEEPSEEK_API_KEY` 与 `DEEPSEEK_MODEL`。进程环境变量优先；修改配置后需要重启服务。密钥仅在后端使用，不放进 H5、文档或聊天记录。

预会面按授权信息加载真实本地账户的相关资料，保持候选真人与分身主人权限隔离。访谈只发送当前账户的相关答案和本会话有限历史；不会读取其他用户的访谈记忆。无密钥时明确使用本地预设/演示流程，调用失败保留用户已输入内容。

## 当前能力

- 本地账户登录会话、用户档案、偏好、会员权益及照片；保留复用本机虚构测试账号的入口。
- 规则推荐和双向反馈，AI 预会面 20 轮或 24 小时先满足即结束。
- 结果分析、独立继续意愿，以及双方同意后的本地 7 天服务状态。
- 四主题轻量建档、旧 11 题兼容、可选聊天式访谈和资料修正。
- 普通偏好总授权、访谈使用范围、撤回及后续回复统一筛选。
- 模型预算、用量、错误处理、访谈问题目的与已问清单。
- 账户注销清理相关资料和访谈数据。

## 测试

从根目录运行 `python premeet-backend/run_tests.py`：使用临时数据库，关闭真实模型请求，不影响本机用户。v0.2.0 共 76 项测试。

浏览器脚本 `ui_light_smoke.py` / `ui_interview_smoke.py` 需要 Playwright、本机 Chrome 和空闲的 4180 端口。脚本自行启动临时数据库测试服务，结束后关闭；需要另行重启日常服务。真实模型验证过程见 `开发记录/`。

## 升级与限制

数据保存在本目录 `sessions.sqlite3`，不提交 Git。升级前使用 SQLite backup API 备份，或停服后复制数据库。本版只新增相关表，保留旧答案与房间。

本地测试登录方式、SQLite 和全局锁仍用于原型验证。尚未对接真实微信与支付，也未完成高并发生产改造。详细设计与限制以根目录产品设计和开发记录为准。
