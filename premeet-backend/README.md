# 知遇本地预会面服务

启动：在本目录运行 `python server.py`，打开 http://127.0.0.1:4180/ 。仅监听本机，不用于公网或真实用户。

## 模型配置

优先读取进程环境变量 DEEPSEEK_API_KEY / DEEPSEEK_MODEL；也可将本目录 `.env.example` 复制为 `.env` 填写密钥。默认模型为 deepseek-flash。修改配置后重启服务，新建会话生效；旧会话保持创建时的模式。不要把密钥放进 h5-mvp 或聊天记录。

有密钥时，请求发送至 https://api.deepseek.com/chat/completions 。只发送固定的虚构授权档案和当前房间的聊天记录，不发送资料采集页的本地数据。没有密钥时使用明确标注的规则演示回复；模型错误时显示错误，失败不计轮，不暗中切换成演示回复。

## 当前范围

- 本地 SQLite 已建立账户、档案、公开范围和会话观察的数据表，并初始化两位虚构测试用户。`/api/account` 提供本地测试身份的列表、本人档案、对方公开档案和公开资料保存接口；它没有真实登录能力，不能用于公网。
- `/api/account` 的 `candidates` 操作会以双方公开档案和私有匹配条件生成规则候选池，返回匹配理由与建议在预会面确认的议题；不使用私密档案、不返回精确匹配分。
- 候选真人可通过 `/api/room` 的 `request` 操作向已开启分身预会面授权的会员发起房间。后端检查角色、可推荐范围和会员并发房间配额，并将双方公开档案快照绑定到房间；同一候选关系的活跃房间会复用，不重复创建。
- SQLite 本地保存房间、消息、截止时间、两个身份的独立决定，以及双方同意后创建的本地 7 天真人接管服务记录；无需安装数据库服务。
- 完整真人发言＋AI 回复计一轮；20 轮或自创建起24小时先到即结束。模型回复晚于截止时间则不追加消息。
- 每次请求检查截止时间，界面倒计时与服务端时间校准；无需每位会员常驻一个 agent。
- 结果页只归纳实际提问、预设的共同交流基础与待真人确认事项，不生成相容性评分或成功概率。
- 绑定房间以本地测试身份隔离：候选真人才能聊天和结束，会员只能查看状态、私密校准和自己的决定；候选真人不能读取会员私密校准，会员不能读取候选真人原始聊天。
- 只有两个决定都为同意才创建 7 天真人接管服务记录。真人接管页仅模拟状态、约见建议、人工协助和安全工单；没有真实微信建群、真人消息或通知投递。
- 敏感问题关键词拦截＋模型提示约束仅供原型验证，不等于完整安全策略。尚无输出事实核验、用户级授权与撤销、限流、删档或上线保障。
- 房间链接仅供本机测试；绑定房间还必须携带对应测试身份，不能仅凭链接操作。

## 验证

`python -m unittest -v test_server.py`

账户接口的验证包含：测试身份初始化、本人可读取私密资料、对方只能读取公开资料、禁止保存未允许公开的字段和档案版本递增。
