# 知遇 Zhiyu

当前版本：**v0.2.0**（2026-11-09），版本号见 [VERSION](VERSION)，变更见 [CHANGELOG.md](CHANGELOG.md)。

知遇是婚恋场景的本地 H5 MVP：资料与偏好 → 数字分身建档 → 可选 AI 访谈 → 推荐与 AI 预会面 → 双方独立决定 → 本地 7 天真人接管服务状态。

## 本地启动

在项目根目录运行：

```powershell
python premeet-backend/server.py
```

浏览器访问 [本地首页](http://127.0.0.1:4180/)。关闭服务或电脑重启后需要重新运行。H5 文件由该服务提供，不要通过 `file://` 直接打开。

模型配置：将 `premeet-backend/.env.example` 复制为该目录的 `.env`，设置 `DEEPSEEK_API_KEY` 与 `DEEPSEEK_MODEL`，再重启服务。已有进程环境变量优先；配置和密钥不要提交到 Git。无密钥时使用明确标注的预设/演示流程。

已有本地账号可以从首页测试入口复用；会员权益通过现有本地运营后台管理。普通注册用户不会自动成为付费会员。

## 模块

| 目录 | 内容 |
| --- | --- |
| `h5-mvp/` | 用户 H5、资料、推荐、轻量建档、AI 访谈、预会面和结果 |
| `premeet-backend/` | Python 本地服务、SQLite、模型调用和自动化测试 |
| `admin-web/` | React 运营后台 |
| `admin-api/` | 运营后台 API，启动方式见该目录 README |
| `产品设计/` | 产品与授权规则 |
| `开发记录/` | 开发进度、测试和已知限制 |

AI 访谈是独立可选模块，不参加也可以使用初始分身。访谈记忆按账户和会话隔离，普通偏好需符合使用范围后才加载到预会面。

## 验证

```powershell
python premeet-backend/run_tests.py
```

测试使用临时数据库并关闭付费模型调用，不改动本机用户数据。v0.2.0 共 76 项后端测试。

浏览器穿测脚本为 `premeet-backend/ui_light_smoke.py` 与 `ui_interview_smoke.py`，需要额外安装开发依赖 Playwright 和本机 Chrome，并先释放 4180 端口；测试结束后需重新启动日常服务。

## 数据与使用范围

数据库、备份、`.env`、上传照片、日志和本地工具不随代码发布。首次运行会按现有代码初始化本地数据库。升级前请备份 `premeet-backend/sessions.sqlite3`；本次升级采用新增表，原有记录保留。

当前仅监听本机，尚未接真实支付或微信建群通知。生产上线仍需正式登录渠道、异步模型任务、并发改造和容量验证。不要将本地无密码测试入口直接开放到公网。

详细进度见 [开发计划与进度](开发记录/MVP开发计划与进度.md)，访谈修复见 [重复提问修复记录](开发记录/AI访谈重复提问修复-20261109.md)。
