# 数字分身核心题库治理表

版本：V1.0（2026-10-26）  
状态：启用中的固定核心题库，共 11 题。

## 使用定位

这不是人格测试、依恋类型判定或“恋爱成功概率”预测。题目只用于建立会员可修改的**相处方式表达**，帮助数字分身在预会面中更自然地回答日常关系话题。

- 允许分身参考：联系节奏、沟通修复、日常陪伴、个人空间、压力支持和协商方式。
- 不允许分身据此推断：婚期、迁居、同居、生育、资产、具体职业安排等重大承诺。
- 用户可以跳过、分次完成或随时修改；不回答不影响使用既有资料建立分身。
- 对外不展示具体选项、分数、标签或“人格结论”。

## 变更规则

1. V1 题干、选项语义和维度不直接改写；修订时新增版本号，旧答案保留所属版本。
2. 新题先以“候选题”状态观察完成率、跳过率、修改率和会后相关性，未通过审查不得加入核心题库。
3. 题目必须用具体情境提问，避免道德评判、心理诊断和诱导性答案。
4. 任何题目都要明确可表达范围；涉及财务、健康、精确住址、婚育决定等敏感或重大事项，只能留给真人确认。
5. 评估目标是改善表达自然度和双方沟通效率，而不是根据答案给用户贴标签或决定其是否“适配”。

## 当前实现

- 后端表：`relationship_question_bank`、`relationship_question_responses`。
- 题目记录保存版本、状态、理论参照、使用范围和选项语义。
- 提交答案后，仅生成一份简短的分身表达包，随分身档案进入预会面上下文；用户以后修改时会覆盖当前答案并重新生成表达包。
- 后续再增加审查日志、题目停用/新版本迁移和低频效果指标，不在 V1 用聊天原文自动改写用户立场。
