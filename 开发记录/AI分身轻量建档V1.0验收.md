# AI 分身轻量建档 V1.0 验收记录

日期：2026-11-08；分支 `codex/lightweight-twin-v1`。原工作未丢弃，未自动提交或推送。

## 实现范围

- 新增统一蓝紫风格轻量建档页面，四类主题、8 个候选问题，支持选择/输入/换题/跳过主题/暂停恢复/随时结束。
- 会员中心和原分身档案连入轻量建档；原 11 题收起为可选补充，保留答案、版本、设置和既有房间。
- 新增按账户隔离的后端状态、草稿、来源记录、修改删除及普通偏好授权。
- 每次预会面回复统一筛选新偏好与旧 11 题；撤回后刷新权限并切断旧表达上下文。
- 新增共享 DeepSeek 调用模块及建档调用次数、长度、超时和 token 记录。修复 HTTP 数据库连接未关闭造成 Windows 临时测试库无法删除的问题。

原有 38 项回归与新增 14 项建档测试，共 52 项。覆盖：旧账号和旧题版本不变、草稿恢复、旧修订冲突、换题跳过、无需答满、单次追问及总调用上限、模型失败先保存答案、无效模型输出仍记录用量、自由文本隐私边界、短兴趣精确摘录、账号隔离、会员限制、授权与撤回、旧 11 题授权和来源校验、缓存摘要绕过防护、旧 AI 消息上下文隔离、删除和注销清理，以及两个新会话的 HTTP 建房与聊天。

## 真实模型检查

使用现有配置与虚构内容“我喜欢徒步”调用 DeepSeek。发现默认思考可能占满短输出额度，已对访谈追问关闭 thinking。修复后实际返回 19 字追问：prompt_tokens=84、completion_tokens=14、total_tokens=98。该数字仅为此次成功验证请求，不代表所有调试请求总费用。此前一次诊断请求共 146 tokens；最初无效输出请求未在调试脚本取回用量，不作为零成本统计。

真实模型检查未使用任何既有用户资料，也没有在正式数据库创建测试数据。模型日常对话质量仍需后续人工体验和持续评估，本次穿测不是模型准确率评测。

## 当前限制

1. 复杂自由输入和旧自由文本校准先作为私密记录保留，不自动对外表达；日常短兴趣摘录仅支持有限词表。
2. 仍沿用现有会员建档权益和本地登录体系，没有改动注册/付费身份规则。
3. 本地服务全局锁下的模型调用会短暂阻塞其他数据库请求；并发部署需改造。
4. 已展示的历史消息不撤销；正在生成中的一条回复不做中途取消，撤回成功后后续请求使用新授权。
5. 未开发集中画像确认、本人试聊、深访谈、量表、语音和完整题库运营后台。

产品和数据规则详见 `产品设计/AI分身轻量建档V1.0.md`。
